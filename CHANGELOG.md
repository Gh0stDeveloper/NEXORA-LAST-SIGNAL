## 0.1.0-alpha.1

### Added

- Independent NEXORA: LAST SIGNAL Godot project.
- 100% local/offline runtime architecture.
- First-person movement, sprint, jump and camera look.
- Automatic hitscan rifle, magazine, reserve ammo and reload.
- Walker, Runner, Crawler, Screamer and Tank variants.
- Infinite local horde waves.
- Local XP, NXC, level and best-wave persistence.
- Main menu, HUD, pause and Game Over summary.
- Android touch controls with held automatic fire.
- Offline networking audit.
- Godot project/gameplay smoke tests.
- Android ARM64 debug build/sign/verify workflow.
- Architecture, testing, offline-contract and roadmap documentation.
